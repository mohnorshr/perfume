## 2024-05-20 - Semantic Buttons and Dynamic ARIA Expansion for Accordions
**Learning:** In single-file custom HTML/JS interfaces, interactive expand/collapse controls (such as accordions and mobile menu toggles) are often implemented using non-semantic `div`s with `onclick` handlers, omitting keyboard focus support and ARIA states. Replacing these with `button` elements, CSS resets (`border: none`, `font: inherit`), `:focus-visible` styling, and JS-managed `aria-expanded` attributes restores full keyboard accessibility without affecting visual design.
**Action:** When auditing custom interactive controls, convert clickable container `div`s into `<button type="button">` elements, add `:focus-visible` outline styles, and dynamically synchronize `aria-expanded` in state transition handlers.
